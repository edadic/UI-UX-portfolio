# RoamAround – Figma UI/UX Design Project  

This repository contains the UI/UX design for **RoamAround**, a prototype for a platform designed to streamline the process of booking guided tours in Bosnia and Herzegovina. Built using **Figma**, this design caters to both mobile and web applications.  

## Key Features  
- **Browse Tours:** View all available tours with detailed descriptions and images.  
- **Filtering Options:** Easily filter tours based on user preferences (e.g., location, type, price range).  
- **User Authentication:** Sign up and log in functionalities for a personalized experience.  
- **Wishlist:** Add tours to a wishlist for future reference.  
- **Purchase Tours:** Seamless booking process for guided tours.  

## Project Details  
The design includes:  
- **Mobile Interface**: A clean and intuitive layout optimized for smaller screens.  
- **Web Interface**: A responsive and user-friendly interface for desktop users.  
- **Interactive Elements**: Fully interactive prototype to simulate user flows.
